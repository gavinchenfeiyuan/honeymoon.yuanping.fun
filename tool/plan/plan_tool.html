💡 使用说明
自动加载同目录 path.json，将 plan（行程计划）渲染为表格。
行可拖拽排序；每行 ✕ 删除；表格可「新建行」；date 显示为 月/日、time 显示为 时/分，保存时合并回 YYMMDD/HHMM。
保存不做校验，按当前顺序与键序直接写回 path.json（缩进 1 空格，末尾带换行）。
保存需 Chrome/Edge：每次保存都会弹出对话框，由你自行选择保存位置（覆盖 path.json 即可）；其他浏览器降级为下载。推荐运行方式：在该目录执行 python -m http.server 8080，访问 http://localhost:8080/plan_tool.html。
每张表格上方内嵌高德地图：按表格行 coordinate 顺序标点并连线，行拖拽/编辑/增删后自动刷新。地图需高德 JS API 类型 的 Key （已内置，顶部输入框可覆盖，填写后刷新页面生效）。
局域网手机访问（iPhone/iPad）：在项目根目录用 python tool/plan/serve.py 启动服务器， 然后用手机 Safari 访问 http://<服务器IP>:8080/tool/plan/plan_tool.html。 保存时自动 POST 写回服务器文件（iOS Safari 不支持保存对话框，故走服务器接口）。桌面本地双击打开则仍用保存对话框/下载。
