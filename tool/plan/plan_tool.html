💡 使用说明
自动加载同目录 path.json，将 plan（行程计划）和 fact（实际行程）渲染为两张表格。
行可拖拽排序；每行 ✕ 删除；每张表可「新建行」；「保存」执行三步：
① 校验每行 name/date 是否存在（缺失则提示并中止）
② 检查 name 是否在 place.json 中存在，不存在的自动创建（填高德 Key 自动查经纬度，查不到的留空待手动补）
③ 按当前顺序写回 path.json，相邻两行 date 不同且中间无 overnight 时自动插入 overnight
保存需 Chrome/Edge：每次保存都会弹出对话框，由你自行选择保存位置（覆盖 path.json / place.json 即可）；其他浏览器降级为下载。推荐运行方式：在该目录执行 python -m http.server 8080，访问 http://localhost:8080/plan_tool.html。
每张表格上方内嵌高德地图：按表格行顺序标点并连线，行拖拽/编辑/增删后自动刷新。地图需高德 JS API 类型 的 Key （已内置，顶部输入框可覆盖，填写后刷新页面生效）。
局域网手机访问（iPhone/iPad）：在项目根目录用 python tool/plan/serve.py 启动服务器， 然后用手机 Safari 访问 http://<服务器IP>:8080/tool/plan/plan_tool.html。 保存时自动 POST 写回服务器文件（iOS Safari 不支持保存对话框，故走服务器接口）。桌面本地双击打开则仍用保存对话框/下载。
